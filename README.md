# Kakobuy Total Cost

Ekstenzija prati sve vidljive redove **Total Price** ili **Total Cost** na Kakobuy stranici korpe, sabira iznose i u donjem lijevom uglu prikazuje zbir u originalnoj valuti i BAM. Promjene se automatski prate.

## Instalacija

1. Otvori `chrome://extensions` ili `edge://extensions`.
2. Uključi **Developer mode / Režim za programere**.
3. Klikni **Load unpacked / Učitaj raspakovano**.
4. Izaberi ovaj folder `kakobuy-total-cost` iz Downloads foldera.
5. Osvježi Kakobuy korpu.

EUR se pretvara po fiksnom kursu 1 EUR = 1,95583 BAM. Za USD, CNY i GBP učitava se aktuelni kurs prema EUR.
